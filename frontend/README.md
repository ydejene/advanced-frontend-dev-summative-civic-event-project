# CivicEvents — Frontend

## Overview

This is the frontend for **CivicEvents — Accessible City Events & Services Portal**, an ALU BSE Advanced Frontend Development summative project.

The frontend is a multi-page static application built with **HTML5**, **Tailwind CSS** and **jQuery**. It consumes the supplied Node.js/Express backend API running on port 4000.

---

## Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic page structure and accessibility |
| Tailwind CSS 3 (CLI) | Utility-first responsive styling |
| jQuery 3.7 | DOM manipulation and AJAX API client |

No frontend framework (React, Vue, Angular) or CSS framework (Bootstrap) is used.

## Setup

### 1. Install frontend dependencies

Navigate to this `frontend/` directory:

```bash
cd frontend
npm install
```

This installs Tailwind CSS and jQuery into `node_modules/`.

### 2. Build Tailwind CSS

```bash
npm run build
```

This compiles `css/input.css` into the minified `css/output.css` file that all HTML pages reference.

### 3. Watch CSS during development

```bash
npm run watch
```

The watch command rebuilds `css/output.css` automatically whenever source HTML or JS files change.

## Serving the Frontend Locally

The frontend is a collection of static HTML files. Serve it with any static file server that correctly resolves absolute paths. From the `frontend/` directory:

**Using Node.js `http-server` (install separately if needed):**

```bash
npx http-server -p 3000 -o
```

**Using VS Code Live Server:**

Right-click `index.html` → Open with Live Server. Set the workspace root to `frontend/` so that absolute paths such as `/css/output.css` and `/assets/images/` resolve correctly.

**Using Python:**

```bash
python -m http.server 3000
```

The homepage will be available at `http://localhost:3000`.

## Backend Connectivity

The frontend communicates with the backend at:

```
http://localhost:4000
```

This base URL is configured in `js/config.js`:

```js
const Config = {
  BASE_URL: 'http://localhost:4000',
  API_URL:  'http://localhost:4000/api',
};
```

**The backend must be running separately before using the frontend.** See `../backend/README.md` for backend setup and start instructions.

To start the backend:

```bash
cd backend
npm run dev
```

The backend connects to the PostgreSQL database `civic-events-db` and listens on port 4000. Confirm it is running by visiting:

```
http://localhost:4000/health
```

A successful response is `{ "ok": true, "env": "development" }`.

## Notes

- Do not edit `css/output.css` directly — it is regenerated by Tailwind CLI.
- Authentication tokens are stored in `sessionStorage` under `ce_token`.
- The Service Requests feature is a browser-local demonstration (no backend persistence).
- Do not add credentials, passwords or secrets to any frontend file.
